The ALU's adder, gate by gate

The 32-bit ripple-carry adder inside the RV32I core's ALU, after synthesis with Yosys. Every gate below is a cell in the synthesized netlist, and every wire's value comes from Yosys simulating that netlist. Bit 0 (the LSB) is on the right; the carry ripples right to left.
