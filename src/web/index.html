C to Gates

For students who want to see the whole stack, from software to hardware: follow one C program through assembly, machine code and the processor's datapath down to its logic gates, cycle by cycle. Every value shown is the verified gate-level simulation of a single-cycle RV32I core.

C source

    Up to 2000 bytes and 60 lines. RV32I has no * / % or floating point, and there is no C library, so no #include (no # at all). It must halt within 500 instructions; main's return value ends up in a0.
