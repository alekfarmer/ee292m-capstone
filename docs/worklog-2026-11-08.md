## What was built

### Round 5 (lrusso3's review)
- The C source pane scrolls like the assembly pane, so a long line no longer
  runs past its box. `tests/test_page_layout.py` failed first.
- The README points to ARCHITECTURE.md's annotated layout rather than keeping
  a second copy; the line-ending report is logged.

### M5: your own C program
- **Page:** a program picker (`sum.c`, `tour.c`, your program) and an editor.
  A rejected program shows one plain message and the old program stays.
- **API:** `POST /api/programs` compiles the program, runs Spike, the gate
  level and the RTL, and runs every M2 check. It answers `u_<hash>`, which
  every existing GET then serves.
- **Limits:** 2000 bytes, 60 lines, one build at a time (503), the 32 most
  recently used kept. A build takes about 1 s, so the request waits for it.
- **Security:** `#include "/work/.env"` was read by gcc's preprocessor, and
  gcc's error message quoted the planted secret. Now `#`, `%:`, `??=`,
  inline assembly and `_Pragma` are refused before any tool runs.
- **`tour.c`** runs every RV32I instruction, which closed the `sltu`-as-`slt`
  blind spot.

### Each cycle explained in plain words
- A panel pinned to the bottom of the window. It says what the instruction
  did, with this cycle's values, gives its line of C, says what to look for
  on the datapath, and has a button that opens a closer view.
- The backend writes the text from the verified trace
  (`src/app/views/explain.py`); the page only shows it.
- `tests/test_explain.py` runs over every cycle of both programs. It checks
  every number against Spike's log, every named block and wire against the
  drawing, and every control value against the RV32I specification.

### Round 6 (my feedback after trying it)
- **Playing:** the window no longer jumps back up. `scrollIntoView` scrolled
  every enclosing box, the window included; now only the assembly pane
  scrolls.
- **Fit to height** next to fit to width, for tall blocks like the result mux.
- **The explanation panel** keeps one height, about 7 lines.
- **Highlight changes:** a changed wire had only a faint 1.2 px gold glow.
  It now has a wide gold band, as the legend shows. A gold outline on the
  values was tried and dropped because it made the numbers hard to read.

### `make up` gets the image itself (PR #15)
- A new `image` target keeps the local image if it matches `docker/`, else
  runs `make pull`, else `make build`. Every container target depends on it.
